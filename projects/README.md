# Portfolio projects

| Project | Prerequisites | Promotion gate |
|---|---|---|
| gpu-kernel-lab | Module 02, selected 03 | Correct kernels, profiler evidence, reproducible comparisons |
| llm-inference-lab | Modules 04–05 | Fair baseline, workload sweeps, measured latency/throughput/memory, clear limitations |
| mini-inference-engine | Module 05, selected 07 | Tested scheduler and bounded request handling; distinguish simulation from real model execution |

Keep exploratory labs in their chapters. Promote mature work into separate repositories only when there is a coherent problem, independent setup instructions, tests, measured results and a clear description of your own contributions. Link the canonical repo here; avoid duplicate maintenance. One polished project is sufficient for the initial portfolio.
