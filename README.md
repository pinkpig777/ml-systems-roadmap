# ML Systems Engineering Roadmap

A self-paced, foundation-first curriculum for ML systems and inference engineering. Learn concepts, implement them, measure results, and turn mature labs into independent portfolio projects.

## Start here
- [Roadmap](ROADMAP.md): seven modules and their chapters.
- [Progress](PROGRESS.md): competency checklist.
- [Resources](RESOURCES.md): primary references.
- [Setup](SETUP.md): local environment and GitHub initialization.
- [Projects](projects/README.md): capstone promotion criteria.

## Workflow
Diagnostic → required reading → implementation → measurement → analysis → assessment → commit. Skip familiar material only when you can meet its exit criteria. Module 07 is cross-cutting. No fixed dates or weekly quotas. Use the RTX 3060 for single-GPU labs; CPU-only simulations are acceptable for distributed concepts, not evidence of multi-GPU performance.

Each chapter includes objectives, targeted reading, notes, questions, and a lab specification. Most labs are intentionally unsolved. The original GPU baseline is provided as starter code, not as measured results.
